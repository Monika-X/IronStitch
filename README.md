# IronSmith Cobblers & Atelier

A luxury, artisan shoe repair and cobbler shop website built using **pure HTML5, CSS3, and Vanilla JavaScript (ES6)** with zero dependencies or frameworks.

## 👞 Theme & Brand Identity
* **Heritage Luxury • Artisan • Refined • Trustworthy • Minimal • Premium**
* **Color Palette:**
  * Espresso (`#2B211D`)
  * Antique Brass (`#B08D57`)
  * Burgundy (`#6E3038`)
  * Sand (`#D8C7AE` & `#E8DBC8`)
  * Ivory (`#F8F4EC`)
  * Charcoal (`#242321`)
* **Typography:** Cormorant Garamond (Editorial Serif) & Manrope (Modern Sans-Serif)

## 📄 Project Structure & 12 Pages
- **Root:**
  1. **Home I** (`index.html`) — Hero slider, stats counters, artisan philosophy, 6-service grid, before/after slider, 4-step craft process, testimonials, FAQ, newsletter.
- **Pages Directory (`pages/`):**
  2. **Home II** (`pages/home2.html`) — Split editorial hero, live counters, tabbed service catalog, lightbox zoom gallery, drop-off timings & map, 3-tier pricing guide, quick repair enquiry.
  3. **About** (`pages/about.html`) — 1947 founding story, 7-decade interactive heritage timeline, master cobblers team profiles, core values, client testimonials, Royal Warrant & press recognition.
  4. **Services** (`pages/services.html`) — 6 signature services with material specs & turnaround, comprehensive price matrix table, materials standard, service FAQ.
  5. **Journal / Blog** (`pages/blog.html`) — Category filters, asymmetric featured post, 6-card editorial grid, reading time & author metadata, custom pagination.
  6. **Blog Details** (`pages/blog-details.html`) — Technical Goodyear welt deep-dive article, workshop diagrams, pull quotes, author bio card, sticky sidebar, related articles.
  7. **Contact** (`pages/contact.html`) — Interactive repair enquiry form with real-time validation, Jermyn Street location schedule, interactive map, London concierge service, national postal service.
  8. **Privacy Policy** (`pages/privacy.html`) — UK GDPR & Data Protection Act 2018 compliant, 10 interactive TOC sections, data subject access rights, cookies policy.
  9. **Terms & Conditions** (`pages/terms.html`) — 10-section legal agreement, quotes, payments, turnaround times, 12-month workmanship guarantee, liability clauses.
  10. **Sitemap** (`pages/sitemap.html`) — Visual tree hierarchy diagram, 4-column categorized directory grid, section anchor links.
  11. **404 Error** (`pages/404.html`) — Animated cobbler shoe visual, floating particle canvas animation, storytelling copy, quick recovery links, heritage quote.
  12. **Maintenance** (`pages/maintenance.html`) — Ambient radial lighting, orbiting tool animation, animated progress bar, live countdown timer, launch notification form.

## ⚡ Interactive Features
* **Theme Modes:** Light & Dark mode toggle with `localStorage` persistence
* **Localization:** LTR / RTL bidirectional layout toggle with `localStorage` persistence
* **Before / After Comparison Slider:** Smooth drag, touch swipe, and click positioning
* **Hero Slider:** Autoplay, arrows, dot controls, touch swipe support
* **Image Zoom / Lightbox:** Fullscreen modal with smooth transitions and keyboard navigation
* **Scroll Reveal Animations:** IntersectionObserver-powered staggered reveals
* **Form Validation:** Real-time feedback, email syntax verification, animated toast notifications
* **100% Unique Imagery:** 66 unique, high-resolution photography assets with zero duplicate images

## 🚀 Running Locally
Open `index.html` directly in any modern browser, or run a local static server:
```bash
# Using Node.js http-server
npx http-server . -p 3000
```
